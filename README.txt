# ParentDent AI – ต้นแบบแอปมือถือ

## มีอะไรในต้นแบบ
- โปรไฟล์เด็ก (ใช้ชื่อเล่น/รหัสแทนชื่อจริง)
- บันทึกภาพช่องปาก
- แผนผังฟันน้ำนม 20 ซี่ (FDI: 55–51, 61–65, 85–81, 71–75)
- แบบประเมินพฤติกรรมที่เกี่ยวข้องกับสุขภาพช่องปาก
- ผู้ช่วยตอบคำถามจากชุดกฎตัวอย่าง (ยังไม่ใช่ AI model)
- บันทึกนัดหมายและประวัติ
- หน้าสรุปสำหรับเจ้าหน้าที่และส่งออก JSON

## ทดลองบนคอมพิวเตอร์
เปิด `index.html` ด้วย Chrome, Edge หรือ Safari

## เปิดบนมือถือและเพิ่มไอคอนหน้าจอ
วิธีที่แนะนำคือเผยแพร่โฟลเดอร์นี้บน HTTPS hosting เช่น GitHub Pages หรือบริการ static hosting ที่หน่วยงานอนุมัติ
1. อัปโหลด `index.html`, `manifest.webmanifest`, `sw.js` ไปยัง hosting
2. เปิด URL ด้วย Safari (iPhone) หรือ Chrome (Android)
3. iPhone: กด Share > Add to Home Screen
4. Android: เมนู Chrome > Install app / Add to Home screen

PWA และ service worker ต้องทำงานผ่าน HTTPS (ยกเว้น localhost) การเปิดไฟล์ HTML โดยตรงใช้ทดลองได้ แต่การติดตั้งแบบ PWA อาจไม่ทำงาน

## ข้อจำกัดและความปลอดภัย
- ไม่มี backend, ระบบล็อกอิน หรือฐานข้อมูลกลาง ข้อมูลอยู่ใน localStorage ของอุปกรณ์/เบราว์เซอร์นั้น
- รูปภาพถูกเก็บในเครื่องผ่าน localStorage อาจเต็มพื้นที่ได้ หลีกเลี่ยงภาพใหญ่
- อย่าใส่ชื่อ-นามสกุล เลขประจำตัว ที่อยู่ หรือข้อมูลระบุตัวเด็กจริงในต้นแบบ
- อย่าใช้ข้อมูลจริงของผู้ป่วยก่อนผ่านการอนุมัติของหน่วยงานและการทบทวน PDPA/ความปลอดภัย
- ฟังก์ชัน AI เป็น rule-based demo ไม่วิเคราะห์ภาพ ไม่วินิจฉัยฟันผุ และไม่แทนการตรวจของทันตบุคลากร
- แบบประเมินเป็นแบบสาธิตที่ยังไม่ได้ผ่านการตรวจสอบความตรง/ความเที่ยง ห้ามเรียกว่าเครื่องมือคัดกรองทางคลินิกที่ผ่านการรับรอง

## แผนพัฒนา 1–2 สัปดาห์
วัน 1–2: ให้ทันตบุคลากรตรวจเนื้อหา แบบประเมิน และข้อความแนะนำ
วัน 3–5: ปรับ UI/ทดสอบบน Android และ iOS
วัน 6–8: ทดลอง usability ด้วยข้อมูลสมมติ
วัน 9–10: แก้ไขและทดสอบความผิดพลาด
วัน 11–14: ทดลองนำร่องหลังได้รับอนุมัติ เก็บความพึงพอใจและความสำเร็จในการทำภารกิจ

## ก่อนนำไปใช้จริง
ต้องเพิ่ม backend ที่ปลอดภัย, authentication/role-based access, consent, encryption, access log, retention/deletion policy และให้หน่วยงานอนุมัติการจัดการข้อมูลเด็ก
